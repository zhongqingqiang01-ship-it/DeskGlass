首次公开发布 DeskGlass · 桌面工作台。

适用于 Apple Silicon Mac、macOS 14 及以上，界面为简体中文。

## 安装

下载 `DeskGlass-0.1.0-macos-arm64.zip`，解压后将「桌面工作台.app」拖到「应用程序」并打开。应用常驻菜单栏；`Control + Option + 空格` 呼出工作台，`Command + ,` 打开设置。

此版本采用 ad-hoc 签名，尚未经过 Apple Developer ID 签名及公证。如果被系统拦截，请确认下载来源后查看「系统设置 → 隐私与安全性」的应用专属「仍要打开」，或按 README 从源码构建。

## 功能

- 常用文件夹、真实文件浏览和操作、拖动排列。
- 本地待办、可选的只读提醒事项与钉钉接入。
- AI 网页和本机应用入口。
- 玻璃面板、位置锁定、主屏定位和大小调节。
- 离线跑车与原创程序化电子小狗。

代码采用 MIT 许可；跑车素材单独采用 CC BY 4.0，并保留作者和来源。公开包不包含高达模型及其贴图，原有动画适配代码仅供兼容的本地资源使用。

## 验证与边界

本机验证：45 项核心行为检查、3 项公开资源与离线加载检查、真实 WebKit 3D 与小狗行为验证，以及构建和签名检查。

未完成：Apple 公证、Intel 实机测试，以及所有真实外部账户环境的端到端验证。项目不需要账户即可使用文件夹、本地待办、工具入口和 3D 展品。

附带 SHA-256 校验文件。可在下载目录运行 `shasum -a 256 -c DeskGlass-0.1.0-macos-arm64.zip.sha256` 检查文件。
