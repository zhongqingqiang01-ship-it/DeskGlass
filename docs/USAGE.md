# 使用指南

## 打开和退出

应用常驻菜单栏，顶部有一个工作台图标。点它可以显示或隐藏工作台、打开设置、移回主屏幕或退出。应用没有 Dock 图标。

| 操作 | 方式 |
| --- | --- |
| 呼出 / 回到桌面层 | `Control + Option + 空格` |
| 打开设置 | `Command + ,`，或菜单栏 → 设置 |
| 移回主显示器 | 菜单栏 → 移回主屏幕 |
| 调整大小 | 拖动右侧工作台左下角斜线，或点自动拉伸按钮 |
| 移动位置 | 先点击锁头解锁，再拖动卡片之间或寄语的空白区域 |
| 退出 | 菜单栏 → 退出工作台 |

## 文件夹

在文件夹区点 `+` 选择本机目录。点击子文件夹进入，点击文件用默认应用打开；路径栏可返回上一级或在 Finder 中显示。

- 拖动文件图标到另一个图标上：只改变工作台里的排列。
- 拖动文件到上方文件夹标签：真实地移入该文件夹。
- 右键可重命名、移动或移到废纸篓。移动和重命名遇到同名项目会停止。
- 标签也可以拖动排序。「从工作台移除」只移除固定入口。

选择目录时可能出现 macOS 的文件访问提示。请按自己的需要授予权限；不需要为日常使用打开全盘访问。

## 本地待办和 AI 工具

待办区点 `+` 添加任务和截止日期。点击圆圈完成或恢复，通过筛选查看已完成任务；本地待办可以右键删除。

AI 工具区可新增网址或选择本机 `.app`，使用系统原有图标。它只负责打开入口，AI 账户、订阅和实际使用在对应应用或网站中完成。

## 外部待办

两类接入都可选，只读展示。不连接时，本地待办照常可用。未连接、未授权、读取失败和真正没有待办分别显示；失败时保留当前会话上次成功读取的结果，不保存到本地缓存。

### Mac 提醒事项

在设置中点击「连接」，再按系统提示允许访问。需要 macOS 14+ 的 EventKit 完整提醒事项读取权限。点击展示出的提醒会打开系统提醒事项应用；在来源应用中完成编辑和勾选。

不同 Mac、系统隐私设置和重新签名可能影响权限，开发时需结合自己的系统验证；首次发布未覆盖所有实际账户环境。

### 钉钉

需要另行安装兼容的官方 `dws`，并拥有自己的钉钉账户和相应权限。本项目不打包该组件，也不要求所有使用者安装它。当前会查找 `/opt/homebrew/bin/dws` 或 `/usr/local/bin/dws`。

当前适配的命令契约：

```sh
dws auth status --format json
dws todo +get-my-tasks --all --status false --format json
```

点击连接且尚未登录时会调用 `dws auth login --format json`，交由 `dws` 处理登录。CLI 返回格式不完整、分页未完成、登录失效或超时都会显示错误，不当作空列表。不同组织和 CLI 版本可能不兼容；本次公开发布未重新登录并验证真实组织账户内容。

## 桌面展品

跑车和小狗完全离线显示。拖动旋转，滚轮缩放，复位按钮恢复视角；切换按钮选择展品。

- 跑车：点击色板换车漆，双击或点互动按钮转动车轮。
- 小狗：点击打招呼，按住来回拖动抚摸，点地面或控制条扔球。也可以喂食、表演、睡觉或叫醒。
- 小狗的心情、电量和休息状态会记住；长时间不操作会进入休息。完全被遮住的展品窗口暂停渲染。

公开版默认只有上述两项。可选的本地机器人模型接入见[开发说明](DEVELOPMENT.md#可选本地模型)。

## 备份、更新与移除

在设置底部打开数据目录，退出应用后备份整个 `DeskGlass` 文件夹。更新时先退出旧版，再替换应用；不要覆盖自己的工作数据。

要移除应用，先从菜单栏退出，再把应用移到废纸篓。卸载应用不会自动删除 `~/Library/Application Support/DeskGlass` 或系统偏好数据，便于以后恢复。只有你不再需要这些数据时，再自行移除。
